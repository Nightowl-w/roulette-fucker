# Roulette Analyzer

A single-page roulette spin tracker and outside-bet breakdown. The app stores spins locally in the browser and includes a two-step reset.

> For entertainment and record-keeping only. Each roulette spin is independent; past results do not predict future outcomes.

## Local use

Open `index.html` in a browser. No build step is required.

## Deployment

Static site deployed on Vercel.
